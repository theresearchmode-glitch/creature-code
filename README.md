# Creature Code

Learn real Python by hatching, training and battling creatures. Your code is the creature's brain.

Built in public by someone learning Python ("learning Python by building a game that teaches Python").

## Play

Open `index.html` in a browser. Python runs right in the page (via [Pyodide](https://pyodide.org)), so there's nothing to install.

## Level 1: Hatch Your Creature

A cozy pixel-art game, built for phones. Old Moss the frog teaches one small idea at a time, quick quizzes check you got it, and in challenges you type real Python yourself (no answers given) to hatch, colour, power up and name your creature. It acts out your code line by line, errors become bugs you catch by fixing them, and finishing the level makes your creature evolve.

New to code? Read [HOW-IT-WORKS.md](HOW-IT-WORKS.md) for a plain-language tour of the game's code.

## Publish it free with GitHub Pages

Repo **Settings → Pages → Deploy from a branch → `main` / root → Save**. A minute later the game is live at `https://<your-username>.github.io/creature-code/`.

All creatures are original designs.
