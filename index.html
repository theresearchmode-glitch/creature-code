Explore Mossbrook, catch wild creatures, and battle with brains you write in real Python.

Turn your sound on

How to play

  • ✥Walk with the D-pad. Wild creatures hide in tall grass.
  • ATalk to people and use things.
  • BSee your team. Every creature's brain is Python code you can read and edit.
  • ⚔In battle: FIGHT to attack. CODE to rewrite your creature's brain (it uses your turn). BAG for jars and berries.
  • ▣Weaken a wild creature, then catch it with a Code Jar by writing its name in Python.
  • ✱Errors spawn bugs. Fix your code to catch them for your bug jar.

Elements

Fire beats leaf. Leaf beats water. Water beats fire.

Bug jar

Empty. Bugs appear when code breaks.
