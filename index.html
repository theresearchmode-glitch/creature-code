How to play

  • 1Old Moss teaches one small idea at a time. Tap the text box to keep going.
  • 2Quick quizzes check you've got it. Wrong answers are fine. You'll see why.
  • 3In challenges, type real Python and press RUN. Your creature acts out each line.
  • 4A bug appears when your code has an error. Fix the code and run again to catch it.
  • 5Stuck? Tap HINT. Each tap gives a bit more help.
  • 6The symbol keys under the code save you hunting for " = ( ) on your phone keyboard.
