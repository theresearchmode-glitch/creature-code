How to play

  • ✥Walk with the D-pad (or arrow keys).
  • ATalk to villagers, read signs, and touch glowing memory stones.
  • BPeek inside your creature's brain: every variable your code made.
  • !Memory stones open a code console. Type real Python, press RUN, and watch the world change.
  • ?Stuck? Tap HINT in the console. Each tap helps a bit more.
  • ✱Errors spawn bugs. Fix your code to catch them for your bug jar.
